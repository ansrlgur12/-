직좌우 개인정보처리방침

시행일: 2026년 11월 13일

직좌우(이하 "앱")는 회원가입 없이 이용하는 게임입니다. 이름·전화번호·이메일 같은 개인 식별 정보를 받지 않으며, 게임에 필요한 최소한의 정보만 아래와 같이 처리합니다.

1. 처리하는 정보와 목적

정보목적보관
기기 식별값 (앱이 처음 실행될 때 무작위로 만드는 값)내 기록·옷장·코인·미션을 이어서 보여 주기서버
닉네임 (직접 정한 이름)함께 한 사람·기록실·랭킹에 표시서버, 기기
게임 기록: 출발지·목적지 이름과 좌표, 걸어간 길, 가위바위보 횟수·거리·시간기록실, 오늘의 월드레코드(하드코어), 다시보기서버
코인, 가진 아이템, 입은 옷, 출석·미션 진행보상과 옷장서버
위치 정보 (사용자가 "지금 있는 곳에서 출발"을 누를 때만)지금 있는 곳을 출발지로 정하기저장하지 않음 (출발지로 정하면 게임 기록의 출발지 좌표로만 남음)

위치는 앱을 쓰는 동안, 사용자가 직접 요청할 때 한 번만 확인하며, 백그라운드에서 추적하지 않습니다.

2. 다른 사람에게 보이는 정보

  • 멀티플레이 방에 함께 들어온 사람에게: 닉네임, 입은 옷
  • 근처에서 게임 중인 다른 방에게: 일행의 지금 위치·옷·걸어간 길만 (닉네임·출발지·목적지는 보내지 않음)
  • 하드코어 모드로 도착하면 오늘의 월드레코드에 닉네임과 기록이 올라갈 수 있습니다

3. 외부 서비스

장소 검색과 지점 이름 찾기를 위해, 검색어 또는 고른 지점의 좌표가 아래 서비스로 전달됩니다. 기기 식별값·닉네임은 전달하지 않습니다.

  • 카카오 로컬 API (주식회사 카카오): 장소 검색, 좌표의 주소·장소 이름
  • OpenStreetMap Nominatim (OpenStreetMap Foundation): 위 검색이 안 될 때 대신 사용

지도는 OpenStreetMap 데이터(© OpenStreetMap contributors, ODbL)로 직접 그립니다. 광고·분석·추적 도구는 쓰지 않습니다.

4. 보관 기간과 삭제

정보는 서비스를 운영하는 동안 보관합니다. 기록이나 정보 삭제를 원하시면 아래 문의처로 앱의 닉네임과 대략적인 플레이 날짜를 알려 주세요. 확인 후 지체 없이 삭제합니다. 앱을 지우면 기기에 있는 정보(기기 식별값·닉네임)는 함께 지워집니다.
